# Nexus Assist

> Локальный виртуальный ассистент для управления операционной системой Windows с помощью голосовых и текстовых команд.

##  О проекте

**Nexus Assist** создан с упором на автоматизацию рутины, минимальное потребление системных ресурсов и обеспечение **доступности (Accessibility)**. Проект работает полностью офлайн на вашем устройстве, а все зависимости и кэш нейросетей изолированы в рабочей папке (например, на диске `F:`), чтобы не захламлять системный диск `C:`.

---

##  Особенности (Features)

*    **Офлайн-распознавание речи:** Использование нейросети **OpenAI Whisper** для высокоточного локального распознавания голоса без задержек и интернета.
*    **Локальная база знаний (RAG):** Быстрый поиск и ответы на вопросы по вашим личным текстовым документам прямо на устройстве.
*    **Умный запуск ПО и Intents:** Нечеткий поиск (`thefuzz`) понимает синонимы, опечатки и разговорный сленг (*«телега»*, *«хром»*), автоматически дописывая новые удачные варианты в конфиг.
*    **Компьютерное зрение (OCR):** Интеграция с *Tesseract* для поиска текста на экране и точного наведения курсора.
*    **Zero-Click управление:** Полный контроль над мышью и клавиатурой без использования рук для максимальной доступности.

##  Стек технологий

*   **Язык:** Python 3.12
*   **Голос:** `openai-whisper`, `sounddevice`, `scipy`
*   **Интеллект и поиск:** `thefuzz`, локальный RAG-движок
*   **Зрение:** `pytesseract`, `Pillow`
*   **Автоматизация:** `pyautogui`
