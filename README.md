# Nexus Assist

## Программа находится в активной разработке.

**Nexus Assist** — это локальный виртуальный ассистент для управления операционной системой Windows с помощью голосовых и текстовых команд. Проект создан с упором на автоматизацию рутины, минимальное потребление ресурсов и обеспечение **доступности (Accessibility)** для людей с ограниченными физическими возможностями.

## ✨ Особенности (Features)

*   **Zero-Click управление (Доступность):** Полный контроль над мышью и клавиатурой без использования рук. Команды для перемещения курсора, скролла и кликов.
*   **Компьютерное зрение (OCR):** Интеграция с *Tesseract*. Скажите `«наведи на [название кнопки]»`, и ассистент сам найдет это слово на экране и переместит туда курсор.
*   **Офлайн-распознавание голоса:** Использование нейросети *Vosk* для постоянного фонового прослушивания. Команды обрабатываются локально, без задержек и подключения к интернету.
*   **Умный парсер намерений (Intents):** Благодаря алгоритму нечеткого поиска (`thefuzz`), программа понимает синонимы, прощает опечатки и адаптируется к дефектам речи (например, поймет «откой баузер» как «открой браузер»).
*   **OBS-Friendly интерфейс:** Графическая оболочка написана на нативном `CustomTkinter`. Полный отказ от тяжелых браузерных движков позволяет легко захватывать окно приложения в OBS Studio без просадок FPS.

## 🛠️ Стек технологий
*   **Python 3.10+**
*   **UI:** `customtkinter`
*   **Голос:** `vosk`, `sounddevice`
*   **Зрение:** `pytesseract`, `Pillow`
*   **Управление ПК:** `pyautogui`
*   **Логика:** `thefuzz`
